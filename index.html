Server Backups — приватний інструмент адміністратора для створення резервних копій PostgreSQL та їх автоматичного копіювання у відведену папку Google Drive.

Цей сайт містить лише опис інструмента та політику конфіденційності. Архіви, облікові дані й токени на цьому сайті не розміщуються.

Для чого потрібен Google Drive

Адміністратор надає доступ через Google OAuth. Інструмент використовує rclone для завантаження резервних копій, перевірки переданих файлів та очищення старих наборів у папці резервування.

Строки зберігання

Запланована політика: локальні завершені копії — 4 доби, копії у Google Drive — 7 діб. Фактичне очищення залежить від успішного виконання завдань і доступності сховища.

Хто користується інструментом

Інструмент призначений для власних серверів адміністратора. Публічної реєстрації та послуг резервування для сторонніх користувачів немає.

Подробиці використання даних наведені в політиці конфіденційності. Зв’язатися з адміністратором можна через профіль GitHub margaretkanyau.
