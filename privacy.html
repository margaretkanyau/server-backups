Призначення та відповідальна особа

Server Backups — приватний інструмент резервування PostgreSQL, яким керує адміністратор акаунта GitHub margaretkanyau. Інструмент працює на сервері адміністратора; цей сайт лише описує його призначення.

Які дані обробляються

  • Архіви баз PostgreSQL, які можуть містити персональні або конфіденційні дані користувачів відповідних баз.
  • Глобальні об’єкти PostgreSQL, зокрема ролі, членство, права та хеші паролів.
  • Назви, розміри, контрольні суми та інші метадані файлів резервування у Google Drive.
  • OAuth-токени, потрібні для автоматичного доступу до Google Drive.

Як використовується доступ до Google Drive

Доступ використовується для створення, читання та перевірки резервних копій і видалення старих файлів у визначеній адміністратором папці. Запитаний дозвіл Google Drive може технічно охоплювати весь Drive; вибір папки в rclone є налаштуванням роботи інструмента, а не обмеженням OAuth-дозволу.

Дані не використовуються для реклами, продажу чи навчання моделей штучного інтелекту. Використання та передавання інформації, отриманої через Google API, має відповідати Google API Services User Data Policy, включно з вимогами Limited Use.

Зберігання та доступ

Копії зберігаються на сервері адміністратора та в його Google Drive. Доступ визначається правами сервера й папки Drive. Токени зберігаються в конфігурації rclone на сервері та не публікуються на цьому сайті чи в репозиторії.

Архіви передаються Google для зберігання у Drive. Їхній вміст не розміщується на GitHub Pages. GitHub як провайдер цього інформаційного сайту може обробляти технічні дані відвідувань за власною політикою конфіденційності. Сайт не містить власних форм збору даних, аналітики або рекламних трекерів.

Строки зберігання та видалення

Запланована політика — 4 доби для завершених локальних копій та 7 діб для копій у Drive. Очищення відбувається під час виконання завдань; помилки можуть збільшити фактичний строк. Незавершені локальні набори можуть залишатися до ручного видалення. Файли, переміщені в кошик Google Drive, можуть зберігатися до його очищення.

Відкликання дозволу та звернення

Власник Google-акаунта може відкликати доступ у налаштуваннях підключених застосунків Google. Це зупинить майбутній доступ, але не видалить уже створені копії. Для видалення копій, уточнення обробки даних або зміни налаштувань зверніться до адміністратора через GitHub margaretkanyau.
